# Employee Management System

A full-stack Employee Management System built with **.NET 8 Blazor WebAssembly**, a **.NET 8 Web API**, and a **SQL database**.

The application provides a secure, role-based platform for managing employees, vacations, overtime, health information, sanctions, users, and roles. It includes authentication, authorization, CRUD functionality, reporting, printing, and export features through a modern Blazor WebAssembly interface backed by the .NET API.

## Features

### Authentication and Authorization

- User registration with email and password
- Secure login functionality
- Role-based access control
- Admin and non-admin user experiences
- Restricted views and functionality for non-admin users
- Protected routes and API endpoints

### User and Role Management

Admins can manage application users and roles, including:

- Create users
- View users
- Edit user information
- Delete users
- Update user roles
- Restricted access based on role permissions

### Employee Management

Users can manage employee records through a complete set of CRUD operations:

- Add employees
- View employee information
- Edit employee records
- Delete employee records
- Print employee information
- Export employee data to PDF
- Export employee data to Excel

### Employee Modules

The application includes dedicated modules accessible from the top navigation bar:

- Employees
- Vacations
- Overtimes
- Health Info
- Sanctions

Each module supports:

- Create records
- Read and view records
- Update existing records
- Delete records
- Print records
- Export records to PDF
- Export records to Excel
